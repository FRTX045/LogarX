# apache-shopfront excerpt

A slice of the Zodiarc Dataset `apache-shopfront` medium build
(`2026-09-07-medium`, seed 19, 243,908 lines), cut by `cut_excerpt.py`:
every line of twelve hostile clients chosen so that each hostile category the
tool knows appears, plus the first forty ordinary clients by first appearance
that have at most 300 lines. 3,825 lines from 52 clients, renumbered from 1,
so `excerpt.truth.jsonl` is a valid truth file on its own.

It is real: every line was written by Apache in response to a request that
was made. Nothing here was generated by a template. The one thing changed is
the time: the build moves each timestamp onto the arrival curves its traffic was
planned against, because the requests were sent far faster than a real week.
The dataset keeps Apache's own times beside them.

`SHA256SUMS` pins the two files and `tests/evaluation/test_fixture.py` checks
them. To recut, point the script at a copy of the full build, which is not in
this repository (see `samples/README.md`); the result is only identical if the
build is the same bytes.
